# Security

This is experimental source without a broad security certification or support SLA. See [privacy boundaries](docs/PRIVACY.md), particularly protected history and optional provider requests.

Do not post credentials, recovery keys, private transcripts, account screenshots or exploitable sensitive details in public issues. If the hosting repository offers private vulnerability reporting, use that route. Otherwise open a minimal issue requesting a private contact channel without including sensitive details. The maintainer identity is [Ghostzy0](https://github.com/Ghostzy0); no email address or additional reporting channel is asserted here.

A useful report gives the affected source/build, platform, minimal synthetic reproduction, impact and expected behavior. Never test against another person's accounts or files. Do not disable OS protection, revoke a working account or alter personal data to reproduce a report.
