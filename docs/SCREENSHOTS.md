# Screenshots

No screenshot acceptance is asserted by this template. The README's SVG is original mascot artwork, not an app screenshot or proof a workflow ran.

Only real captures of the current app with synthetic content may be added. The export supports these reviewed filenames:

| File | Intended coverage | Exact build/edition/host/result |
| --- | --- | --- |
| `docs/assets/baseline-workspace.png` | Native baseline workspace | Pending capture and review |
| `docs/assets/pip-workspace.png` | Pip workspace | Pending capture and review |
| `docs/assets/pip-setup.png` | Pip setup | Pending capture and review |

Replace each pending cell with the actual capture date, source/build identity, edition, macOS/architecture, state/input and limits when adding that image. Do not label a render fixture as a real interaction. Never include credentials, account identifiers, private files or copied proprietary reference assets. Image appearance does not certify inference, persistence, motion, accessibility or privacy.
